# First Customer Checklist

Confirm approved terms and support contact; create the customer organization; verify owner email; complete onboarding; store the one-time SDK key in a server secret store; send a test event; confirm dashboard totals; set warning and hard-stop budgets; prove `/policy/check` is honored before provider calls; configure an alert destination; select the correct plan through hosted checkout; confirm subscription/entitlements/invoice; record consent/support evidence; monitor the first 24 hours; never request provider credentials through support messages.
