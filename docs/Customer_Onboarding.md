# Customer Onboarding

1. Register and verify the email address.
2. Sign in; confirm the default organization and owner role.
3. Choose Python, Node or REST and create a scoped TokenWatch SDK key.
4. Copy the secret once into a server-side secret manager.
5. Install/use the documented SDK, send the built-in test event and verify its receipt.
6. Confirm dashboard request/token/cost totals.
7. Create a monthly budget with warning and hard-stop thresholds.
8. Call `/policy/check` before every provider request and honor blocks; ingest actual usage afterward.
9. Invite teammates with least privilege and configure alerts.
10. When billing is activated, upgrade only through hosted Stripe Checkout and manage changes in the portal.
